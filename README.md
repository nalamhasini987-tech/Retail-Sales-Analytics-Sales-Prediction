# Retail Sales Analytics & Sales Prediction

## 📌 Project Overview

This project analyzes retail sales data to understand product, category, customer, and regional sales performance. It also uses **Linear Regression** to predict sales based on important sales-related features.

## 🎯 Objectives

- Analyze retail sales performance.
- Identify top-performing products and regions.
- Study relationships between quantity, discount, and sales.
- Analyze monthly sales trends.
- Predict sales using Linear Regression.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📊 Analysis Performed

- Data cleaning and preprocessing
- Missing-value handling
- Duplicate removal
- Date and time analysis
- Product-wise sales analysis
- Category-wise sales analysis
- Region-wise sales analysis
- Customer-type analysis
- High-value transaction analysis
- Correlation and covariance analysis
- Sales distribution analysis
- Monthly sales trend visualization

## 🤖 Sales Prediction

A **Linear Regression** model is trained using:

- Quantity
- Unit Price
- Discount

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## 📈 Visualizations

The project includes visualizations such as:

- Top products by sales
- Category-wise sales
- Region-wise sales
- Correlation heatmap
- Scatter plots
- Sales distribution
- Monthly sales trends
- Actual vs Predicted Sales

## 🚀 How to Run

1. Open the notebook in **Google Colab**.
2. Upload the `retail_sales_project_dataset.csv` dataset.
3. Run the cells step by step.
4. View the analysis, visualizations, and prediction results.
